This is a romhack of Pokemon Emerald using pret's decompilation project for the game.

You build it the same as you do any other decomp based hack. Check their install.md for details if you don't know.

But, the premise of this hack is to bring all of Gen 3 into a single title; both as a 386 hack and to include Johto, using vanilla RSE and FRLG assets when possible. Further iterations of the hack with later generation mons are to be worked on following the completion of this version, the original, which is meant to be compatible with vanilla gen 3 and Pal Park. Extra areas will be added in those versions to accomodate new encounters and legendaries, but as far as whole regions go, Kanto, Johto, Hoenn and Sevii are all that will be in any version.

Currently this is an incomplete build, with the Sevii Islands mostly complete in terms of mapping. Kanto's exteriors and dungeons are done, Johto's exteriors are being worked on. You can reach them via a disembodied door in Petalburg City. From there, the debug map can take you to any complete or mostly complete exterior town. The white path indicates that a route is pretty much set, with minimal adjustments needed. Doors lead you directly to the corresponding town. Grass paths indicate either in-progress, or in the case of Trainer Tower's interiors, maps that aren't implemented yet. Blacked out means no maps in the corresponding section. All the necessary names have been changed to accomodate all of Johto. Further changes will be made in later editions made with expansion.

Encounters are partially complete, as are warps. Ferry functionality is currently nil, but you can use fly from any of the outdoor maps back to Petalburg. Make sure to pack repels, escape ropes, Dig, and whatever else you might need. 

For that reason, I recommend using a save file that at least has Surf to explore fully, and Fly to get back to Hoenn.
Region maps aren't functional yet, so each outdoor map just shows up like you're in the top left corner of the map. Teleport also works to bring you back to any vanilla Pokecenter, as while Sevii's centers do have complete interiors, they have none of the related scripts. 
For the moment, vanilla saves function well. If need be, I will try to provide a save file for exploring when future commits that add more trainers alter the saveblock.
